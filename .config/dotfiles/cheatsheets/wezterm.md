## WezTerm

[← Index](index.md)

| Key / Alias | What it does | Source |
| --- | --- | --- |
| `CTRL+a` | **Leader** prefix for the bindings below | `~/.config/wezterm/wezterm.lua` |
| `CMD+n` | `SpawnTab "CurrentPaneDomain"` | `~/.config/wezterm/wezterm.lua` |
| `CMD+w` | `CloseCurrentPane { confirm = true }` | `~/.config/wezterm/wezterm.lua` |
| `SHIFT+LeftArrow` | `ActivatePaneDirection "Left"` | `~/.config/wezterm/wezterm.lua` |
| `SHIFT+DownArrow` | `ActivatePaneDirection "Down"` | `~/.config/wezterm/wezterm.lua` |
| `SHIFT+UpArrow` | `ActivatePaneDirection "Up"` | `~/.config/wezterm/wezterm.lua` |
| `SHIFT+RightArrow` | `ActivatePaneDirection "Right"` | `~/.config/wezterm/wezterm.lua` |
| `LEADER+\` | `SplitHorizontal { domain = "CurrentPaneDomain" }` | `~/.config/wezterm/wezterm.lua` |
| `LEADER+-` | `SplitVertical { domain = "CurrentPaneDomain" }` | `~/.config/wezterm/wezterm.lua` |
| `LEADER+LeftArrow` | `AdjustPaneSize { "Left", 5 }` | `~/.config/wezterm/wezterm.lua` |
| `LEADER+RightArrow` | `AdjustPaneSize { "Right", 5 }` | `~/.config/wezterm/wezterm.lua` |
| `LEADER+DownArrow` | `AdjustPaneSize { "Down", 5 }` | `~/.config/wezterm/wezterm.lua` |
| `LEADER+UpArrow` | `AdjustPaneSize { "Up", 5 }` | `~/.config/wezterm/wezterm.lua` |

> **Note:** `LEADER` in the table above means press `CTRL+a` first.
