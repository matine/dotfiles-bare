## Herdr

[← Index](index.md)

### Global

| Key / Alias | What it does | Source |
| --- | --- | --- |
| `` ctrl+` `` | **Prefix** leader for the `prefix+…` bindings below — Backtick has no ASCII control code, so this relies on the Kitty keyboard protocol, which Ghostty enables by default. | `~/.config/herdr/config.toml` |
| `prefix+?` | Help — Herdr's own keybinding overlay, the fastest way to look a chord up in situ. | `~/.config/herdr/config.toml` |

### Workspaces

| Key / Alias | What it does | Source |
| --- | --- | --- |
| `ctrl+alt+w` | Next workspace | `~/.config/herdr/config.toml` |
| `ctrl+alt+shift+w` | Previous workspace | `~/.config/herdr/config.toml` |
| `prefix+w` | Workspace picker — Up and down keys move between workspaces. | `~/.config/herdr/config.toml` |
| `prefix+ctrl+n` | New workspace | `~/.config/herdr/config.toml` |
| `prefix+ctrl+x` | Close workspace | `~/.config/herdr/config.toml` |
